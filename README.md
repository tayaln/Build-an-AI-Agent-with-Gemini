### AI Search Agent using Gemini

This notebook accompanies the lesson on AI Agents and demonstrates how to build a simple AI Search Agent using Gemini 2.5 Flash, LangChain, and SerpAPI. 

As you work through the notebook, pay attention to how the agent decides when to use an external tool, performs web searches, validates information, and generates a final response. 

This hands-on exercise will help you understand the key difference between a traditional LLM and an AI Agent that can reason and act using external tools.
